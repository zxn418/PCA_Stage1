# Accelerating Image Filtering Using Multicore Parallel Processing
ARTI 503 – Project Stage 1: Proposal and Sequential Benchmarking
Group 2 (9FA3)

## Files
- `GaussianBlur_sq.ipynb`: sequential Gaussian Blur + benchmark
- `Sharpening.ipynb`: sequential Sharpening + benchmark
- `small/medium/large/xlarge/xxlarge_*.png`: test input images (256² to 4096²)
- `gaussian_*.png`, `sharpened_*.png`: filtered output images

## How to run
1. `pip install numpy pillow`
2. Update the image paths in the notebooks to where the images are stored.
3. Run each notebook top to bottom.
